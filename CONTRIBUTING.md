Thanks for your interest in contributing to FreqWave EQ! Contributions of all kinds are welcome — bug reports, documentation fixes, tests, and code changes. Feature requests as well!

Getting started

1. Fork the repository and create a feature branch from `main`.
2. Install dependencies:

```bash
npm install
```

3. Run the development UI:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```

Guidelines

- Branch naming: `fix/issue-123-description`, `feat/short-description`.
- Keep changes focused; open a draft PR if the change is large.
- Follow existing code style (TypeScript + React functional components, TailwindCSS for styles).
- Run `npm run lint` and fix any lint errors before submitting a PR.

Pull requests

- Target branch: `main`.
- Include a clear title and description, reference related issues (`#123`).
- Add screenshots or recordings for UI changes.
- Add tests where practical.

Issues

- Before opening an issue, search existing issues and PRs.
- Provide a minimal reproduction, steps to reproduce, and expected vs actual behavior.
- Contact me directly.

Security

If you discover a security vulnerability, email me directly rather than opening a public issue.

Thanks — I will review PRs and issues on a best-effort basis.
